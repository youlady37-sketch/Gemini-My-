# ✨ HH Reply AI — Chrome Extension для hh.ru

Персональный AI-помощник для анализа вакансий на **hh.ru** и генерации точных, естественных сопроводительных писем на основе подтвержденного опыта кандидата (**Татьяна Павлович, Key Account Manager**).

---

## 1. Что делает расширение

1. **Автоматически распознает вакансию на hh.ru**: определяет заголовок, компанию, зарплату, локацию, обязанности, требования и ключевые навыки.
2. **Работает в Google Chrome Side Panel**: открывается в аккуратной боковой панели браузера, не загораживая страницу вакансии.
3. **Структурирует требования вакансии**:
   - Что совпадает с вашим опытом в B2B-продажах.
   - Что совпадает частично.
   - Что не подтверждено профилем.
   - Какие достижения лучше всего упомянуть именно для этой позиции.
4. **Создает живое сопроводительное письмо**:
   - Без клише, канцелярита и роботизированных фраз.
   - Не выдумывает опыт и не преувеличивает.
   - Автоматически использует только стандартные кавычки `" "` и суммы в `руб.`.
   - Автоматически добавляет контактный блок в конце.
5. **Позволяет адаптировать тон в 1 клик**:
   - «Переписать» (сбалансированное)
   - «Короче» (емкое до 500-600 знаков)
   - «Живее» (энергичный тон)
   - «Больше конкретики» (упор на факты и цифры)
   - «Больше про бизнес» (фокус на LTV и выручку)
   - «Убрать канцелярит» (максимально простой человеческий язык)
6. **История откликов**: сохраняет до 20 последних вакансий с возможностью повторного копирования или удаления.

## 2. Системные требования

- Браузер **Google Chrome** версии 116+ (с поддержкой Chrome Side Panel API).
- **Node.js** версии 18 или новее.
- Менеджер пакетов **npm** (устанавливается вместе с Node.js).

## 3. Установка Node.js

Если Node.js еще не установлен:
1. Перейдите на официальный сайт [nodejs.org](https://nodejs.org/).
2. Скачайте версию **LTS** (Recommended for Most Users).

   ```bash
   node -v

   ```

## 4. Установка зависимостей проекта

Откройте терминал в папке проекта и выполните:

```bash
npm install
```

Команда загрузит все необходимые библиотеки для сборки React и расширения.

---

## 5. Сборка расширения

Для сборки расширения выполните стандартную команду:

```bash
npm run build
```

После выполнения команды в корне проекта появится папка **`dist`**. В ней будут сформированы:
- `manifest.json` — конфигурация Manifest V3;
- `sidepanel.html` — интерфейс боковой панели;
- `background.js` — фоновый Service Worker;
- `content.js` — контентный скрипт для извлечения вакансий с hh.ru;
- `icons/` — иконки расширения.

---

## 6. Как установить расширение в Google Chrome

1. Запустите браузер Google Chrome.
2. В адресной строке введите и нажмите Enter:
   ```text
   chrome://extensions
   ```
3. В правом верхнем углу страницы включите переключатель **«Режим разработчика»** (*Developer mode*).
4. В левом верхнем углу нажмите появившуюся кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
5. В открывшемся окне выбора папки выберите папку **`dist`** из проекта.
6. В списке расширений появится карточка **HH Reply AI** с иконкой ✨.

---

## 7. Как открыть Side Panel на hh.ru

1. Откройте любую вакансию на сайте [hh.ru](https://hh.ru), например:
   `https://hh.ru/vacancy/109847291`
2. Нажмите на иконку пазла (Расширения) в правом верхнем углу Chrome и закрепите булавкой **HH Reply AI**.
3. Кликните на иконку **HH Reply AI** — справа в браузере откроется боковая панель (*Side Panel*).
4. Расширение сразу покажет данные открытой вакансии.
5. Нажмите кнопку **«Разобрать вакансию и создать письмо»**.

---

## 8. Как обновить расширение после изменений в коде

Если вы изменили код в папке `src`:
1. Выполните сборку:
   ```bash
   npm run build
   ```
2. Откройте страницу `chrome://extensions`.
3. Найдите карточку **HH Reply AI** и нажмите на иконку **«Обновить»** (круглая стрелка).
4. Изменения применятся мгновенно.

## 10. Архитектура AI и подключение внешних API

В первой версии расширение работает **полностью автономно и детерминировано** без необходимости оплачивать или настраивать внешние ключи:
- Встроен интеллектуальный слой сопоставления требований вакансии и опыта Татьяны в `src/services/aiService.ts`.
- Он подбирает только реальные факты и формирует живой человеческий текст.

### Как подключить реальный AI API (Gemini / OpenAI / Claude)

**ВАЖНО ПО БЕЗОПАСНОСТИ:**
Никогда не вставляйте секретный API-ключ непосредственно во frontend-код расширения (`manifest.json`, `content.js`, `App.tsx`), так как unpacked-расширение в браузере доступно для чтения.

Для подключения внешнего AI предусмотрена прокси-архитектура:
1. Разверните простой бэкенд (или Cloud Run / Serverless endpoint).
2. На бэкенде реализуйте эндпоинты:
   - `POST /api/analyze`
   - `POST /api/generate-cover-letter`
   - `POST /api/rewrite`
3. В файле `src/services/aiService.ts` укажите адрес вашего бэкенда:
   ```ts
   aiService.setConfig({
     provider: 'server_proxy',
     apiUrl: 'https://ваш-сервер.com/api'
   });
   ```
4. Бэкенд считывает `GEMINI_API_KEY` или `OPENAI_API_KEY` из своих защищенных переменных окружения (`process.env`) и обращается к AI, возвращая готовый текст в расширение.
